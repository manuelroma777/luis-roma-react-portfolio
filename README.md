# Manuel Vasquez Roma React Portfolio Application

# 👨‍💻 Luis Roma – Portfolio Profesional en React

Este es el portafolio web de **Luis Manuel Vásquez Roma**, desarrollado con **React**. Presenta los principales proyectos personales, conocimientos adquiridos, experiencia profesional, e incluye un formulario de contacto para facilitar la comunicación con potenciales empleadores o colaboradores.

---

## 🧾 Descripción General

Este portfolio fue creado como carta de presentación digital. Tiene como objetivo principal mostrar habilidades técnicas, proyectos destacados, intereses y disponibilidad para trabajar en el área del desarrollo web Full Stack.

🧪 Cómo ejecutar el proyecto localmente
Clona el repositorio:

git clone https://github.com/manuelroma777/luis-roma-react-portfolio.git
cd luis-roma-react-portfolio

Instala las dependencias:
npm install

Ejecuta el servidor de desarrollo:
npm start

Abre tu navegador en:
http://localhost:3000

💡 Recomendaciones
Asegúrate de tener Node.js y npm instalados correctamente.
Usa un editor como Visual Studio Code para una mejor experiencia de desarrollo.
Personaliza las imágenes, enlaces y textos en el portafolio para reflejar mejor tu identidad profesional.
